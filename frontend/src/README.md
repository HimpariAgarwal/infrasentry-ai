
# InfraSentry AI

An AI-powered infrastructure intelligence platform
for detecting, monitoring and prioritising urban
infrastructure damage.

## Vision

To transform infrastructure maintenance from
reactive reporting into proactive, data-driven
decision-making.

## Core Modules

- Computer Vision Damage Detection
- Geospatial Intelligence
- Temporal Defect Tracking
- Risk Prioritisation
- Repair Verification

## Technology Stack

- Python
- FastAPI
- React
- TypeScript
- PostgreSQL
- Computer Vision
- Machine Learning
