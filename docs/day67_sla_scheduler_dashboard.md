# Day 67 — SLA Scheduler Analytics Dashboard

## Features
- Scheduler running/stopped status.
- Total, successful and failed executions.
- Average execution duration.
- Success rate indicator.
- Last and next execution timestamps.
- Recent execution history.
- Automatic refresh every 30 seconds.

## API endpoints
- GET /api/v1/sla/scheduler-analytics
- GET /api/v1/sla/scheduler-status
