# Day 103 - Protected System Diagnostics API

## Endpoint

GET /api/v1/system-diagnostics

## Authentication
Requires a valid JWT Bearer token.

Unauthenticated requests receive HTTP 401.

## Response
Returns the system diagnostics JSON generated by the
Day 102 diagnostics module.

## Security
- Reuses the existing get_current_user dependency.
- Does not create a separate authentication mechanism.
- Does not return environment variables or credentials.
- Internal errors use a generic HTTP 500 response.
- Existing /api/v1/system-health behavior is preserved.

## Tests
Run:

python -m unittest backend/test_system_diagnostics.py backend/test_system_diagnostics_api.py -v

## Integration
The existing system_router is already registered in main.py.
No additional main.py registration is required.
